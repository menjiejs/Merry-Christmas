# 给你的圣诞树

原生 HTML、CSS、JavaScript + Python WSGI + SQLite。本地学习不需第三方依赖；正式部署使用 Gunicorn + 宝塔 Nginx。

正式上线与容量限制见 [宝塔部署说明](deploy/宝塔部署说明.md)。默认上限：10000 棵树、100000 枚装饰；限流配置需在宝塔启用后生效。

## 打开网站

在 VS Code 打开项目，选择“终端 → 新建终端”，输入：

```sh
python3 server.py
```

浏览器访问 http://127.0.0.1:8000 。以后使用这个地址，不再双击 index.html。
停止服务：在终端按 Ctrl+C。

## 使用

1. 点击“种下我的树”，填写称呼，生成 /tree/随机编号。
2. 点击“分享这棵树”。
3. 访客选择装饰、填写称呼与留言、点击挂点。选择位置期间才显示空挂点。
4. 挂好后可点击装饰查看留言，也可通过弹窗创建自己的树。

每个浏览器通过持久 Cookie 获得随机编号，每棵树只能送一次。换浏览器、清除 Cookie 或使用无痕模式可绕过限制；共用浏览器的人也共用这一次机会。网站不采集设备指纹。

树和留言通过链接公开可见，请勿填写隐私信息。没有登录或私人留言功能。

## 文件作用

- index.html：页面结构、样式、SVG 圣诞树和背景动画。
- app.js：手绘 SVG 装饰、输入表单、挂点、调用服务器、弹窗与链接分享。
- server.py：提供网页及接口，设置 Cookie，检查重复赠送和位置冲突。
- data/trees.db：运行时生成的 SQLite 数据库。关掉服务后备份整个 data 文件夹。
- test_server.py：使用临时数据库测试共享、重复赠送、冲突、并发和重启恢复，不改真实留言。

旧版 localStorage 留言仍留在浏览器中，不自动导入新树。

## 手机与公开分享

127.0.0.1 只指向当前设备，不能直接发给朋友。
同一 Wi-Fi 测试时可停止服务后运行 `python3 server.py --host 0.0.0.0`，在手机访问“电脑的局域网 IP:8000”。从手机和电脑都使用相同局域网地址分享，端口保持一致。

要跨网络分享，需要部署到有持久磁盘的 Python 托管服务，并设置 HTTPS 和固定域名。项目已提供正式服务入口和限速配置，但尚未部署到互联网；公网请按宝塔说明运行 Gunicorn 并配置 Nginx。SQLite 文件必须放在持久磁盘，不能放在会被每次发布清空的目录。

## 验证

```sh
python3 -m unittest -v test_server.py
node --check app.js
```

## 冬夜音乐与留言管理

右上音符按钮可播放/暂停 Scott Buckley 的 Snowfall（CC BY 4.0）。默认关闭，点击后才请求约 2.37 MB 的压缩音乐，页面“音乐鸣谢”保留曲名、作者、来源与授权链接。部署需上传 assets/music/snowfall.mp3；宝塔可用附带的精确音频路径配置直接传输，不占 Python 处理线程。

新创建的树会记录当前浏览器为树主人。树主人点开装饰后可二次确认移除留言；其他访客没有删除权限。移除后赠送者仍算送过一次。清除 Cookie、换浏览器或域名不会自动继承主人权限。旧树若没有创建者记录，不能仅凭同名认领，需要有证据时在线下绑定。

赠送历史只保留去标识的浏览器摘要用于防重发，不保留被移除的留言正文；旧备份可能仍包含删除前内容。10万条容量上限按赠送历史计数，包括已移除的装饰，防止反复删除令历史无限增长。
