# 已上线服务器升级：私密留言与多次赠送

保持现有 Nginx、域名、HTTPS 和 1 进程 2 线程的 systemd 配置，不添加限流。新代码自动升级数据库版本0到1；升级保留树、留言、主人及开发者浏览器记录。旧留言保持公开，之后可由主人设为私密。

以下操作在已部署的宝塔服务器终端逐条执行。有任何失败，先停止后续步骤，不要删除数据库，不要直接运行旧版代码。

```bash
cd /www/wwwroot/christmas
systemctl stop christmas-tree
```

先备份（名称带时间，不覆盖之前备份）：

```bash
.venv/bin/python deploy/backup.py --database /www/wwwroot/christmas/data/trees.db --output /www/backup/christmas
```

确认“备份已完成”后继续：

```bash
git pull --ff-only origin main
.venv/bin/python -m unittest -v test_server.py
```

测试只使用临时数据库；测试通过后启动，真实库将在首次请求时自动迁移：

```bash
systemctl start christmas-tree
curl -fsS http://127.0.0.1:8000/healthz
```

返回 {"ok":true} 后，用同一个 Safari 刷新正式网站。现有树链接和开发者绑定都保持；清理 Cookie 会失去原身份，升级时不要清理。

在另一浏览器验证：发送多条装饰；勾选私密的正文只对发送者和树主人显示；第三个浏览器看不到正文；主人可把公开留言设为私密。挂饰和名字仍公开。移除的挂点可复用，历史赠送继续占全站总量。

若启动失败：

```bash
systemctl status christmas-tree --no-pager
journalctl -u christmas-tree -n 60 --no-pager
```

保留备份并查看错误；数据库格式已变化，不要只把代码退回旧版。备份数据库含留言内容，不要上传GitHub或发送给第三方。
